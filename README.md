## 🛠️ Kurulum Adımları

1. **Tek Tıkla Ekleme (Önerilen):** Mavi butonlara tıkladığınızda CloudStream otomatik açılır ve depoyu yükler.
2. **Manuel Ekleme:** Bağlantı açılmazsa, kutudaki URL'yi kopyalayıp uygulama içinden **Ayarlar > Eklentiler > Depo Ekle** adımlarını izleyin.
